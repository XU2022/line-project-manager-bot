# 任务指令

以下示例默认通过LINE的真实`@机器人`提及触发。不能提及时，可以使用部署者配置的备用字母；例如备用字母为`P`时，以`P:`或`P：`开头。

## 新增任务

```text
@机器人 新增任务“演示任务”，由我负责，截止10月15日
@机器人 创建任务“示例检查”，负责人是Bob，截止2026-10-20 16:30
```

建议使用引号包住任务名称。只写日期时，默认截止时间为18:00，可在初始化指令处理器时修改。

## 更新任务

```text
@机器人 更新 TASK-0001，阶段改为审核
@机器人 修改 TASK-0001，负责人改为Alice
@机器人 更新 TASK-0001，截止2026-10-22 12:00
@机器人 TASK-0001 当前受阻
@机器人 TASK-0001 恢复执行
```

默认阶段示例为规划、执行、审核、交付。也可以使用自定义阶段名称。

## 完成或取消

```text
@机器人 TASK-0001 已完成
@机器人 取消 TASK-0001
```

## 查询

```text
@机器人 查询当前任务
@机器人 任务列表
```

查询结果只显示尚未完成和尚未取消的任务，并使用成员配置中的显示名称。

## 当前限制

- 指令解析是确定性规则，不会把普通聊天交给大模型猜测。
- 只有结构化`@机器人`或句首备用前缀会触发；手动输入机器人名称不会触发。
- 成员必须先写入成员表；未登记成员不能执行任务操作。
- 当前版本尚未提供群内成员登记命令。
- 当前版本尚未启动HTTP webhook服务，也不会主动发送Push消息。
