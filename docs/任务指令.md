# 任务指令

以下示例都需要以 `H:` / `H：` 开头，或者在LINE中真实提及机器人。

## 新增任务

```text
H：新增任务“演示任务”，由我负责，截止10月15日
H：创建任务“示例检查”，负责人是Bob，截止2026-10-20 16:30
```

建议使用引号包住任务名称。只写日期时，默认截止时间为18:00，可在初始化指令处理器时修改。

## 更新任务

```text
H：更新 TASK-0001，阶段改为审核
H：修改 TASK-0001，负责人改为Alice
H：更新 TASK-0001，截止2026-10-22 12:00
H：TASK-0001 当前受阻
H：TASK-0001 恢复执行
```

默认阶段示例为规划、执行、审核、交付。也可以使用自定义阶段名称。

## 完成或取消

```text
H：TASK-0001 已完成
H：取消 TASK-0001
```

## 查询

```text
H：查询当前任务
H：任务列表
```

查询结果只显示尚未完成和尚未取消的任务，并使用成员配置中的显示名称。

## 当前限制

- 指令解析是确定性规则，不会把普通聊天交给大模型猜测。
- 成员必须先写入成员表；未登记成员不能执行任务操作。
- 当前版本尚未提供群内成员登记命令。
- 当前版本尚未启动HTTP webhook服务，也不会主动发送Push消息。
